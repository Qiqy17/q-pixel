# 五项稳定性工作验收

## 第一项：保存、退出、恢复

- 修复：恢复草稿按钮现在遵守当前未保存作品的离开确认；取消保留当前画布与草稿入口；保存或库操作期间不允许恢复。
- `python3 tests/native-lifecycle.py docs/qa/2026-10-10-stability`：16 项通过。临时编译实际 Mac AppDelegate，仅注入 QA 回报与加载地址；随机 Bundle ID、独立静态服务，不读取生产作品。覆盖实际进程正常终止/重开与 SIGKILL 后重新启动，正文/图层/进度和提交草稿恢复。
- `npm test`：25 个 JS 文件、14 个 Python 用例通过。`npm run build`、`git diff --check` 通过。
- 真实 NSSavePanel 文件保存与退出保护面板的手动点击尚未验收；原生 UI 自动化入口两次超时。未操作原有生产 App 会话/恢复草稿。
- 源码通过不表示已安装新 App。真实 iPad 与实物制作分别待验收。

## 上传约定

源码、测试脚本和不含用户作品的验收记录推送至任务分支 `stability-20261010`。远端 main 与本地现有开发历史不同，任务分支保留本地已验证基线，不改远端 main、不强制推送。

## 第二项：备份容量与独立恢复

- 生成前显示包括可读历史、草稿、遗漏清单与校验字段的容量；超限禁用生成，允许减少勾选或“选择可容纳的一批”。分批选择明确标注未选作品及未包含草稿，不自动导出或上传。
- 完整文件仍在生成时再次核对，不把预估当作已备份。单作品 .qpx 的历史范围与同机副本限制明确说明。
- 新增测试：中文/遗漏/草稿/待同步记录的预计字节与实际包一致、1001 条分批、草稿单独超限、混合遗漏项容量。
- 原生脚本增至 21 项，包含真实 WebKit 备份容量界面与批次按钮、校验和、独立 IndexedDB 完整正文恢复。测试库与文件保存面板的人工验收分别记录。
- `npm test`（25 个 JS、14 个 Python）、构建、差异检查通过。原生 21 项通过。

## 第三项：离线入口保护与 iPad 验收准备

- Service Worker 只删除 Q像素旧缓存，保留同 origin 的其他应用缓存；只拦截同 origin 请求；缺失脚本/图片不再收到离线 HTML，导航才返回离线页。
- 单元测试验证缓存清理、跨 origin 与 API 请求隔离、导航/资源的离线失败行为。
- 隔离 Chromium 真实注册 Service Worker，断网刷新并重新打开保存作品，恢复网络后作品上传请求为 0，无页面错误。浏览器报告包含大图预检，不能当作真实 iPad 验收。
- `npm test`（26 个 JS、14 个 Python）、构建、差异检查通过。
- 2026-10-10 `xcrun devicectl list devices`：iPad 8 unavailable。不操作原 Safari 数据、配对码、恢复草稿。待设备在线后逐项核查：导入→触控编辑→本地保存→关闭重开→离线打开→后台恢复→导出→用户手动同步，横竖屏各一次；失败保护原作品并记录重现步骤。

## 第四项：制作与输出质量

- 检查真实格子/备料用量一致性、未知色号、四邻域碎色；仅提示，不改色/删格。底板数量使用用户当前规格，大图无需为显示数量重复遍历全部底板。
- 检查面板与逐板 PDF 明确镜像方向、非 1:1 及试印核对格距要求。现有 PDF 按页面适配，不把它描述为实物定位模板。
- 样例 60×40 包含空格与角落标记，用量/分板坐标重建一致；异常用量、未知色号与碎色测试通过。实际 Chromium 快照选 15×15 底板后显示 4 块，不再沿用默认 29×29。
- 实际按钮导出 4 页 PDF，pdfinfo 核对 A4（595.28×841.89 pt），最终四页均渲染并目视核对标题、非镜像/试印说明、坐标、图纸与用量表；保留现有格距与页内布局，不宣称已物理标定。导出样例完全为合成 QA 数据。
- `npm test`（27 个 JS、14 个 Python）、构建、差异检查通过。物理打印格距、真实用豆/缺货和熨烫成品对比待用户实测；3D 仍未标定。

## 第五项：更新回归与大型作品

- 3D 工作台加载/关闭/重新打开与导出使用独立代次，旧成功、旧失败、旧进度和取消后的文件结果不能修改当前预览；取消后允许重试。
- 新增 5 项浏览器异步回归，使用真实工作台与受控渲染器/迟到 Promise 注入，不宣称这些注入是物理 GPU 验收。
- 真实 Chromium 另运行 120×120、500×500 双图层的实际画笔、撤销、保存、重开及实际 2D/3D 标签切换，16 项检查通过、无页面异常。性能记录仅为本机桌面 Chrome 基线；预览计时反映引擎与模式切换可用，不表示全部表面细节生成完毕或真实 iPad 的性能。
- 不再把合成图生成/颜色处理计入工程打开计时；不把更换测试样例前后的数字当作性能提升证据。底板数量显示已避免全图分板遍历，碎色检查使用无临时坐标数组的四邻域扫描。
- 新增 `scripts/verify_stability.sh`：单元/服务测试→构建→差异检查→隔离原生进程→隔离浏览器与 PDF 导出。浏览器需要 Node 20+、Playwright 和本机 Chrome；通过 `QPIXEL_QA_NODE`、`QPIXEL_QA_NODE_MODULES` 指向已安装运行时，不自动安装依赖。
- 页面与离线缓存统一到 `20261010-stability-65`。服务版本测试比较实际页面和接口，不再把历史版本号硬编码为长期预期。
- 完整回归：27 个 JS 测试文件、14 个 Python 用例、21 项原生检查、16 项浏览器检查通过。真实 iPad/实物/原生文件面板的待验收状态保留。

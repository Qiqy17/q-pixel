# 离线大图备份与 PDF 纸张尺寸验收（2026-09-29）

## 目标与改动

- 昨日 500 × 500 验收发现：本机缓存不足且电脑工程 API 不可用时，保存状态正确显示“未保存”，但提示所指的源文件导出按钮位于不可进入的 `version` 阶段。
- 编辑器顶部常驻“备份 .qpx”；保存失败文案直接指向该按钮。浏览器直接下载 Blob，原生 App 仍通过系统导出桥接；下载不将当前工程误标为“已保存”。
- A4/A3 PDF 的 `/MediaBox` 使用物理纸张尺寸，图纸按比例居中放入。纸张方向随界面设置；PNG 导出像素尺寸不变。

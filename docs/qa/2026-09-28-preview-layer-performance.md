# 大图预览分层性能验收（2026-09-28）

## 改动

- 2D 编辑画布在单格小于 3 像素且图纸不少于 1 万格时，使用缓存的栅格概览；单格编辑只更新对应缓存像素，平移和缩放不再重复统计全部豆数或重组图层。
- 导出预览独立按屏幕预算生成，最长边以 2048 像素为目标；正式导出沿用原设置。分区预览的预算按页数分配，拼接结果限制最长边。
- 超过 2 万颗的 3D 图纸先显示可交互颜色概览；近距离再分批建立逐颗几何，融合表面沿用分条构建。3D PNG 导出会等待完整模型。
- 更新网页脚本和离线缓存版本，使电脑和平板获取新实现。

## 验证

- `npm run build`、`npm test`：17 个 JavaScript 测试文件和 5 个 Python 测试通过；`git diff --check` 通过。
- Chromium 本地浏览器，120×120 合成图纸：正式导出画布为 8464×8716；屏幕预览为 1800×2002，像素量约为正式导出的 4.9%。
- Chromium 本地浏览器，500×500 合成图纸：导出预览为 1620×1866，生成约 77 毫秒；旧脚本为 21762×22011。编辑画布尺寸为 930×420，连续缩放调用约 0–1 毫秒（浏览器主线程计时，未含屏幕刷新）。
- 500×500 的 3D 图纸已在浏览器中目视检查：首次显示颜色概览，放大后状态提示融合表面已就绪，并显示对应细节。

## 范围

- 测试图纸为合成数据，数据生成本身约耗时 11 秒，不计入预览时间。
- 浏览器测试在本机 Chromium 完成；平板设备的实际帧率和网络表现仍需在设备上观察。

# 本机管理台验收

2026-10-09（北京时间），用户确认第一版本机只读管理台。

- /admin、/admin.html、/admin.js、/api/admin/* 仅回环、非代理、非配对服务开放；Host/Origin 检查仍启用。编码／规范化路径也受检查；HEAD/POST/DELETE 不开放管理写入。
- 页面显示版本、服务探测、电脑作品索引（含已删除）、历史备份下载及结构化日志计数。不输出日志正文或凭据，不提供删除和恢复覆盖。
- 原生 App 通过固定地址桥接在默认浏览器打开管理台，保留创作窗口；浏览器入口新页打开。待同步和冲突只统计当前浏览器同地址的 IndexedDB，以 readonly 读取；没有数据库时中止创建，不写保存区。
- 管理页面不纳入离线缓存，接口与管理资源 no-store；CSP、frame-ancestors 和 nosniff 已设置。旧索引过期时只读扫描作品，绝不触发迁移或重建落盘。

验证：23 个 JS 文件、7 个服务安全用例通过；另有 2 个管理模块用例验证远程客户端／代理拒绝、过期索引、摘要字段白名单和不写文件。构建和 diff 检查通过。

独立 QA 服务 127.0.0.1:8894、数据目录 /tmp/qpixel-admin62-qa：实际管理页面刷新后显示三个测试作品（含已删除记录）；HTML 标签标题按文本显示；搜索后准确剩一条；备份链接与接口返回已核对。读取、备份导出不改原数据。真实平板、原生编辑／文件保存全流程不在这次管理台验证范围内。

后台是本机运维管理，不包含用户会员／订单／云端内容后台。历史 JSON 备份不等于完整本机作品库备份。部署及安装验证另补。

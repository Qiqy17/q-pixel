# Q像素 2.0 改版基线

记录日期：2026-09-22  
基线提交：`ecc251c`  
适用阶段：2.0 里程碑 A 开始前

## 当前有效功能

- 首页：本地与远端项目列表、最近项目、历史版本、复制、重命名、回收站。
- 编辑器：像素画与拼豆图纸模式、画笔/橡皮/取色/选区/形状/辅助线、图层、撤销与重做。
- 导入：快速导入可直接进入编辑；高级优化可以进入、返回、取消或使用当前结果。
- 保存：本地项目索引与独立 payload 缓存、远端同步、历史版本和冲突副本。
- 输出：PNG、拼豆像素画、图纸与分区相关输出设置。
- 效果预览：现有 Canvas 2D 材质与场景预览（仅作为兼容功能，不等同于写实 3D）。
- 拼制：颜色顺序、当前色统计、完成格记录、自动跳转与未完成格定位。

## 自动回归基线

- `node --check`：`app.js`、导入引擎、导入处理和 Worker 全部通过。
- `tests/import-engine.test.js`：通过。
- `tests/import-processing.test.js`：通过。
- 项目 payload 夹具：8×8、80×60、500×500 稀疏、500×500 密集。
- 新增保护范围：项目正规化、指纹、历史恢复、冲突副本、功能开关、工作区状态、一次性模块加载。

## 默认行为约束

- `professionalWorkspace`、`patternRebuild`、`photoreal3d` 默认全部关闭。
- 开关关闭时继续使用当前稳定首页、编辑器和导入路径。
- 新模块加载失败不得阻止旧工作区显示；未来功能入口负责捕获失败并回退。
- 旧 `.qpx` payload 继续可读；缺少版本号时按版本 1 迁移。

## 发布检查

- 安装包不得包含 `test.html` 或测试产物。
- 页面新增运行时文件必须同时进入离线缓存、macOS Resources 和 SHA-256 清单。
- 每个里程碑均运行 Node 回归、浏览器回归、临时 macOS 打包与签名校验。

# 去背景精细选取与分区工程设计

## 目标

去背景窗口可独立缩放、滚动查看并选择四邻接的同色号像素。画布编辑可把当前可见图纸复制为新的分区工程；每块在同一视图中显示、独立编辑与统计，并沿用区域导出预览选择。

## 方案

- 去背景窗口保留原有自动识别和选区增减。增加“连通同色”工具，点击一个有色像素，以四邻接查找完全相同色号的连通块，将结果加入或移出当前选区。显示比例由 CSS 控制，源画布分辨率不随缩放反复创建；提供适应、放大、缩小、滚轮及滚动查看，指针坐标按显示矩形映射回原图。
- 在画布编辑加入行数、列数和“生成分区工程”。默认 3×3，每轴最多 4 块且不得超过原图尺寸，避免全尺寸图层占用过多内存。按比例分配余数，所有原图像素恰好落入一个区块。操作先保存原工程，再生成新 ID、新标题及独立图层。每个图层的 `tileRegion` 是不可重叠的编辑边界，图层格子在边界外为空。工程保存 `tileLayout`；旧工程继续按原格式打开。
- 分区工程的绘制会在指针落入区块时激活对应图层，所有写入遵守图层边界。图层列表显示区块尺寸及该块色号统计；画布显示区块边界。分区工程锁定会破坏分区对应关系的全图变形与图层结构操作。导出区域来自分区边界，勾选框支持单选、多选、全部；导出预览与 PDF 使用勾选结果，每页分别计算局部色号。

## 验证

验证连通选区不会跨不同色号或对角接触；非整除尺寸切分不丢失或重叠；工程保存与重开保留图层、边界和导出选项；编辑不会跨区块；实际浏览器与打包资源版本一致。

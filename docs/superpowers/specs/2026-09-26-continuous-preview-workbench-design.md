# 连续预览工作台设计（已确认）

用户确认：保留一个预览入口，3D 与平面只切换中央画布；图纸编辑时在同一工作台切换到可编辑网格，返回展示图立即刷新。默认观察，明确选择编辑后才能落笔。

## 结构与交互

- 顶部为成品 3D / 平面展示图；中央画布保留当前模式、独立缩放和 3D 视角，右侧折叠面板及图层不随标签切换消失。
- 两种模式共用烫法、3D 视角、光影与布景、3D 图纸背板、图纸显示、真实工具栏、图层和撤销记录。3D 专属设置在平面页仍可修改，切回 3D 即可观察结果。
- 平面页观察时展示完整平面构图，保留文字、贴纸、边框和原导出链；点“编辑图纸”后，中央改为独立的可编辑网格画布，共用 Q像素编辑工具、图层、色板、色号、网格和辅助线。点“查看展示图”回到构图。所有编辑进入同一工程历史，实时更新 3D 与平面预览。
- 平面展示图沿用现有适应 / 加 / 减及手势缩放；平面编辑网格有独立的适应 / 加 / 减和拖移；3D 沿用滚轮、双指、视角按钮及放大缩小。切换标签不重置各自缩放和视角。
- 狭窄屏幕将设置面板排到画布下方，保留顶部标签和编辑状态；控制区可独立滚动，避免挤压画布。

## 数据与边界

- 共享背景、光影由平面设置状态作为单一数据源；3D 背板与烫法仍是各自的工程设置。图纸编辑只改变可编辑图层，不烘焙布景或贴纸。
- 打开和关闭工作台时临时移动既有工具、图层和平面控件，并用锚点原位恢复；避免复制控件造成两套状态。
- WebGL 不可用时，保留平面展示图和网格编辑，明确提示 3D 不可用。

## 验收

桌面和平板分别检查：两标签与编辑状态切换；设置与图层始终可达；修改背景、光影、烫法和背板后正确显示；网格落笔、撤销/重做、图层锁定、色号/网格/辅助线；三种画布独立缩放；平面构图元素可继续操作并导出；关闭后主编辑器控件恢复。完成模块测试、浏览器回归、安装包资源及签名核验。

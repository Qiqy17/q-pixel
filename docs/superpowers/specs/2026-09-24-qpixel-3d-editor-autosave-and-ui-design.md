# Q像素圆融成品、3D 编辑、自动草稿与工具界面设计

日期：2026-09-24  
状态：用户已确认设计；待书面规格复核  
适用：本地 Web、macOS App、平板浏览器

## 1. 目标与现状

本轮落实六项需求：成品 3D 的软化融边与可调纹理；编辑器顶部和工具栏重排；可选周期自动草稿；可用的版本恢复；3D 中的色号、网格与长按同色提示；3D 中实时编辑完整像素画或拼豆图纸。

当前成品 3D 的融合色块使用方正网格外缘；14 种烫法已有表面差异，但纹理覆盖、粗糙度和融边不可单独调。图纸工具栏在专业工作区会合并为一根长栏。草稿在修改后约四秒写入本机，尚无用户可选间隔；历史版本列表和恢复代码已存在，但恢复当前版本时依赖远端工程读取。3D 工作台只有双击拾色和观察，没有编辑命令。

用户提供的七张《各类烫法展示数据》仅作视觉参考。它们不能用于 MARD 5 mm 的绝对颜色、尺寸、温度或反射率标定；原图不进入 App。成品工作台持续显示“参考模拟 · 未实物标定”。

## 2. 实施路线

采用共享图纸和编辑命令：2D 与 3D 读取同一工程、图层、色号、撤销栈和保存状态；3D 把射线拾取的格子交给现有编辑操作，收到变更后增量刷新预览。这样不会产生独立 3D 草稿，也不用重写项目格式。

备选路线及取舍：独立 3D 编辑数据在关闭时同步，无法满足实时一致；整体重写编辑器会扩大旧工程和工具回归范围。采用共享命令路线。

工程顺序为：保存与恢复数据安全 → 顶部和工具 UI → 3D 几何与材质控制 → 3D 覆盖信息、长按和全工具编辑 → 完整打包验收。每一批独立通过检查后推送代码；最终安装的 App 对应同一 Git 提交。

## 3. 自动草稿、手动保存与版本恢复

### 3.1 自动草稿

提供“关闭、15 秒、30 秒、1 分钟、3 分钟、5 分钟”选项，默认 3 分钟。选项保存在本机偏好，不写入图纸色号或材质参数。图纸变脏后开始计时；间隔到达时只保存**可恢复草稿**，不改变“未保存”提示，不更新项目正式版本，也不增加历史版本。连续绘制期间最多写一个最新完整草稿，关闭页面前尝试完成当前草稿事务。没有改动时不重复写。

保留现有完整事务与崩溃恢复机制，给大工程优先使用可容纳完整工程的本机存储；写入失败时保持未保存状态并给出导出工程提示。打开时只对比草稿和正式工程的时间与指纹，向用户提供恢复、稍后两个动作，不静默覆盖。手动保存成功后清除对应草稿。自动草稿不会使用户误以为正式工程已保存。

### 3.2 手动保存与恢复

手动保存才更新正式工程。只有有意义的内容变化才生成历史快照；版本记录包含时间、标题、尺寸、来源（手动或恢复）及可预览缩略图，沿用有界历史容量。版本入口在编辑器顶部和项目列表都能到达。

恢复优先读取本机完整工程及历史；若缺失再读取电脑服务。恢复前先记录当前正式版本，离线时也能恢复并继续编辑。预览历史版本应创建不覆盖原工程的临时预览，恢复动作才替换当前工程；失败不改动当前状态。远端同步失败显示“已保存在本机，待同步”，不伪称同步成功。已有旧工程与历史结构保持可读。

## 4. 编辑界面与图标

按用户当前截图调整顶部：品牌与返回按钮留足间距；工作模式、画图/配色/拼制/导出阶段清楚分组；导入、保存、预览、导出与更多操作不挤在左上角。中等宽度允许操作区自然换行，画布上方的尺寸与缩放栏保持独立，避免按钮相互覆盖。

工具栏分“绘制、区域、辅助”三个可折叠组，默认展开当前工具所在组；一次最多展开一组。每个工具保留原 ID、键盘焦点和功能，组切换不修改当前工具。采用一套原创、线条圆润的 SVG 小图标，分别表达画笔、取色、橡皮、移动、填充、矩形、选择、形状、辅助线、配色、描边、色板和清空等含义；同时提供文字标签或悬停提示，不能只靠颜色识别。触控按钮至少 44×44 CSS px。工具选项浮层不覆盖主要画布交互，移动端可滚动。

## 5. 成品 3D 形态与材质

融合表面仍无孔、无豆间黑缝，但外轮廓与色块交界采用连续共享边界的软化轮廓：圆角、轻微鼓起与可重复的低幅不规则性模拟塑料熔融。正反面拓扑继续按烫法区分；“融边程度”从低到高改变轮廓圆润度与色块边界的软化量，不改变格子占用或色号。极端值不得制造缝隙、跨格串色或吞掉孤立豆。

右侧增加三个独立滑杆：纹理粗糙程度、纹理透明度、融边程度。粗糙程度调整微表面法线和反射扩散；纹理透明度仅调整纹理层可见强度，**不修改透明豆的材质类别或项目色号**；融边程度调整几何轮廓。各烫法有不同默认值，用户改动作为工程的 3D 设置保存，切换烫法时显示该烫法默认值及当前覆盖值，并可一键复位。七张图用于对照毛巾、澡巾、布纹、横纹、细闪和粗闪的相对颗粒、方向与高光，不推导实测数值。

中性对照光、冷暖、曝光、浅深底和固定正反斜视角继续可用。确保白色、浅色、透明豆在同一场景有区分；4K 导出使用与屏幕相同的设置。500×500 大图按块构建，不因滑杆拖动逐颗同步重建整幅图。

## 6. 3D 覆盖信息、长按与编辑

右侧提供“显示色号”“显示网格”开关，以及“色号透明度”“色号大小”滑杆。色号按每颗豆中心投影，按当前视角遮挡和视口裁剪；网格对齐实际 5 mm 豆位。大图只创建可见范围内的标签，缩得过小时以可读性阈值隐藏并提示。快照与导出按用户开关包含或排除这些覆盖信息。

触摸或鼠标按住一颗豆超过 2 秒且未移动时，全部同色号豆位亮起；松开或切换工具后取消高亮，长按本身不产生绘画或撤销记录。短点执行当前工具，拖动连续绘画。画布始终用于编辑；旋转、俯仰与缩放使用独立按钮，避免拖动含义冲突。空格也可临时查看视角，但按钮路径必须完整可用。

3D 工作台复用全部当前像素画/拼豆工具：画笔、橡皮、取色、填充、矩形操作、选区及移动、形状、描边、辅助线、配色与色板、图层选择与锁定、撤销重做。工具参数与 2D 同步；3D 拾取包含空格子，编辑受图层可见、锁定和透明锁限制。一次拖动只建立一个撤销检查点；变更立即更新共享图纸、2D 画布、豆数与 3D 表面。关闭 3D 不提交第二份副本，也不丢失已落笔的修改。WebGL 失效时保留 2D 编辑与自动草稿。

## 7. 验收与边界

- 用 7 张参考图对应的无孔、织物和闪面特征做视觉对照；检查低、中、高融边值的轮廓及多色交界，无孔模式不出现黑缝。
- 在 49×49 彩色工程中逐项操作 3D 工具；2D 与 3D 即时一致，长按不会误画，撤销重做正确，锁定图层不会被修改。
- 对 15 秒和 3 分钟自动草稿做定时验证；自动草稿不清除“未保存”，手动保存才产生正式历史；离线恢复保留恢复前版本。
- 在用户截图相近的桌面窗口、820×1180 平板、1024×768 和窄屏检查顶部与工具栏，按钮可达且无横向溢出。
- 30×30、120×120、500×500 检查 3D 交互与内存降档；4K 导出、默认测试页、专业工作区测试页、打包 App、服务健康、资源哈希和 Git 提交一致后发布。

受控 MARD 样片与目标 iPad 实机未提供前，本轮只称参考模拟和桌面/浏览器验收，不称完成实物色差标定或 iPad 实机验收。

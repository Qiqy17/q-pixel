# 图层画布外内容保留设计

日期：2026-09-29

## 目标

普通工程的每个图层保留独立的完整格子矩阵及其在画布坐标中的位置。画布只显示相交部分。图片和 `.qpx` 图层导入、图层移动均不删除画布外的格子；移回或扩容后重新显示。

## 数据

- 现有 `layer.cells` 继续作为画布范围内的可编辑投影。仅对位置或尺寸与画布不同的图层保存 `contentCells`、`originRow`、`originCol`，作为完整内容。旧工程缺少这些字段时按画布大小、原点 `(0,0)` 读取。
- 移动只改变原点，再生成可见投影。画布外非空格不计入画布统计、导出和 3D 预览；工程源文件和撤销快照保留它们。
- 画布内编辑同步回完整内容；新增的格子超出原内容边界时扩展内容矩阵。锁定、透明锁、显示状态保持原有语义。
- 导入 `.qpx` 时保留所有可见源图层的完整内容并居中；导入图片时按图片比例生成独立格数的完整图层，最长边仍受现有 500 格限制。显示范围内的投影与原工程其他图层正常合成。

## 操作边界

- 普通工程图层可上下左右移动指定格数，无裁切确认。锁定图层及分区工程不能整体移动。
- 画布扩容只改变可见范围；向上或向左扩容时相应移动图层坐标，保持旧画布内容位置。明确执行裁剪画布、合并图层时，结果只保留当前画布内内容。
- 画布缩放和图层镜像应同时变换完整内容与位置，避免画布外格子失配。
- 工程保存、备份和重新打开必须恢复完整内容；图层逐个另存保留完整内容，合并另存只包含当前画布可见内容。

## 验证

验证图片与 `.qpx` 大于画布的导入、移出和移回、扩容显示、画布内绘制、撤销重做、源文件保存重开、离线缓存、分区限制、500×500 响应，以及安装包和电脑/平板服务。已经被旧版本裁掉且无原文件或备份的格子无法自动恢复。

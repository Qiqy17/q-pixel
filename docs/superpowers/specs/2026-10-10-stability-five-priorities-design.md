# Q像素五项稳定性改进与验收

日期：2026-10-10。用户已授权按五项逐个实现、检验、测试、上传。应用市场工作暂缓。本文件具体化已确认的任务，待用户审阅后开始实施。

## 交付方式

采用逐项复现、最小修复、回归、独立提交的方式。相比一次重构，逐项交付更容易定位失败与回退；相比只补文档，实际操作验收能发现平台及恢复路径问题。不进行无关重构。

“上传”按推送本任务源码、测试与验收记录到现有 GitHub origin 理解；不上传用户作品、恢复草稿、配对凭据、证书私钥或诊断中的个人资料。无 App Store 发布。安装更新与 GitHub 推送分别记录。

每项完成运行针对性测试、npm test、npm run build、git diff --check。涉及安装包时另执行发行校验与资源哈希检查。失败不标记通过，不能用浏览器结果代替真实设备结果。

## 共同约束

- 一个写入者，实施前检查并保护并发改动；不覆盖用户作品或已打开会话。
- 采用独立数据目录、浏览器入口和测试作品。原生测试使用独立应用身份与存储，验证隔离后才运行。
- 保存先落本地；恢复、导入、更新、网络恢复均不自动上传作品，同步仅由用户明确触发。
- 保留色号、图层、制作进度、历史及恢复草稿。失败或取消不清除未保存状态。
- 不添加服务器、账号、支付或收费服务，不承诺未标定 3D 与实物一致。

## 1. 保存、退出与异常恢复

复现 Mac 原生编辑、保存、正常退出、重开，以及保存期间继续编辑、导出取消、服务失败与强制终止。使用真实 WKWebView、退出对话框和文件保存面板，不仅调用页面函数。

必要修复围绕保存状态、草稿恢复及原生桥接回调，沿用现有模块。写入失败保留旧可读数据和当前修改；异常终止后恢复最近成功持久化的版本，明确显示恢复状态，不承诺恢复尚未持久化的操作。

通过条件：正常保存前后正文、色号、图层及制作进度一致；取消不误报保存；失败可重试；有未保存修改时退出保护生效；异常恢复可另存或返回，未经用户操作不覆盖原作品。

## 2. 备份与恢复

保持现有 qpxlib 校验、非覆盖导入与 50 MiB/1000 条限制，增加生成前容量预检、可理解的分批选择提示和遗漏清单；首先核查现有界面，已有行为不重复实现。

测试包含真实文件导出、独立存储导入、容量边界、历史/草稿/回收站及损坏文件。外部副本通过用户选择导出目录实现，不自动上传或写入外部位置。

通过条件：用户知道实际备份内容与遗漏；超限有可执行分批路径；取消与失败保护数据；独立环境恢复后关键字段一致。若单个作品加历史超过上限，明确拒绝完整库包并提供单作品备份路径及其历史覆盖范围，不能伪装完整备份。

## 3. 真实 iPad 继续制作

先核查设备可用性与配对条件。测试导入、触控编辑、本地保存、退出/重开、离线入口、切后台恢复、手动同步与导出，覆盖横竖屏及面板切换。

修复可复现的触控、布局、生命周期及离线问题，不清理原浏览器站点数据，不改变入口来绕过备份。迁移先备份，再导入核对。

通过条件：真实 iPad 完成连续任务，关键数据保持一致；断网明确本地状态；恢复网络不自动同步；重试与冲突不丢双方版本。设备不可用时继续浏览器/WebKit预检，但真实设备验收保持待完成。

## 4. 导入至实物质量检查

检查现有尺寸、色号、碎色、备料缺口、分板方向和打印比例提示。只补充缺失或错误的检查，不自动改色、不强制阻断用户合理选择。

采用固定小样与多板样例核对图纸/BOM/打印输出的一致性。实物制作由用户配合记录实际尺寸、色号、用量与方向。3D 保持未标定说明。

通过条件：导入至导出全程色号与占用格守恒；缺货全部列出；分板可复原；打印尺寸和方向可核对。真实成品比对独立验收，数字检查不能代替实物通过。

## 5. 更新回归与大型作品性能

将前四项可自动运行的关键路径组成隔离回归入口，补充首页继续制作、撤销、图层操作、备份恢复及更新数据兼容检查。基于实际热点做小范围模块拆分，不全面重写 app.js。

在相同设备、数据和场景记录 120×120、500×500 双图层的打开、编辑、撤销、保存、重开、2D/3D切换耗时与失败情况。对未测设备不设置推测性能承诺；优化前后同条件比较。识别明显长任务时提供进度、取消或降级路径。

通过条件：核心回归可重复执行；旧测试作品可读且字段不丢；取消不会使旧异步结果覆盖新作品；关键操作性能无超过测量波动的退化，发现退化则先定位修复。真实设备表现另记录。

## 顺序与验收状态

按 1→2→3→4→5 实施；设备或实物条件缺失不阻断独立的软件工作，但不得将该项标记完全验收。每项记录实现、测试、包、安装、GitHub推送、真机和实物的独立状态。推送不表示本机已更新，本机更新不表示公开上线。

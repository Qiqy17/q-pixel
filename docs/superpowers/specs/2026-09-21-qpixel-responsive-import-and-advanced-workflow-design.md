# Q像素响应式导入与高级制作流程设计

日期：2026-09-21  
状态：用户已确认设计，等待书面规格复核

## 目标

解决大图点击“快速导入”后界面长期无响应的问题，并在不牺牲颜色匹配质量和本地隐私的前提下，引入三项高价值高级能力：图层阿尔法锁定、相近色智能合并、按色号制作导航。

本次交付同时修复快速导入实际使用“均衡”算法、结果摘要却可能显示“高保真”的状态不一致问题。发布后，本地仓库、GitHub `main` 和已安装 macOS App 必须记录同一 Git 提交。

## 现状与根因

使用 3840 × 2560 同类图片复现时，点击“快速导入”后约 22 秒才完成。按钮本身可以触发，但同步计算占满网页主线程，期间无法重绘、关闭、取消或反馈进度，因此用户感知为“点不动”。

当前采样流程会对每个网格内的多个像素重复执行 221 色调色板的 CIEDE2000 全量匹配。以常见 48 × 32 图纸为例，可能产生数千万次色差运算。图片预处理、色号匹配、清理、切换工作模式和渲染还在同一个点击事件中连续执行。

## 竞品学习与取舍

颂拼豆公开功能包括照片转图纸、16–256 画布、色号统计、色板合并/删除/替换、原图对比、图纸分区、阿尔法锁定、自定义贴图、立体拼豆、智能板与创作者生态。Q像素已具备原图对比、图层、制作进度、图纸分区、PNG/PDF 导出、材料表现等能力，因此本轮不重复建设这些功能，也不引入账号、社区、付费或硬件依赖。

本轮选择直接提高创作与实际制作效率的三个缺口：阿尔法锁定、可解释的相近色合并、按色号制作导航。颂拼豆公开评价中出现的大图卡顿、按钮难点击和导出失败也作为反面验收项：Q像素所有重计算必须可见、可取消、不可覆盖当前任务。

## 架构

### 导入任务控制器

主页面新增单一导入任务控制器。每个任务具有不可复用的 `taskId`、阶段、进度、取消标志、输入设置和结果。任何工作线程消息在应用前都必须同时匹配当前会话编号和当前任务编号。新图片、关闭导入、取消或重新开始时，旧任务立即失效；迟到结果不得写入状态。

任务阶段固定为：

1. `prepare`：缩放并取得不可变像素数据；
2. `adjust`：曝光、对比度、饱和度、降噪、抖动与连通背景处理；
3. `match`：网格采样与色号匹配；
4. `cleanup`：模式清理、锁定色分析和统计；
5. `complete`：一次性提交结果。

### 独立工作线程

新增独立 Worker，接收可转移的像素缓冲区、目标网格、色板 Lab 数据、导入类型和处理设置。Worker 返回纯数据图纸，不访问 DOM、不修改全局状态。

色号匹配采用量化颜色缓存。RGB 输入先按固定精度生成缓存键；未命中时仍使用完整 CIEDE2000 与 221 色调色板比较，命中后直接复用结果。缓存具有容量上限并按任务复用，避免无界增长。质量基准保持 CIEDE2000，不退回纯 RGB 最近色。

### 备用流程

若浏览器不支持 Worker、Worker 创建失败或执行异常，控制器自动切换到主线程分段版本。分段版本按有限行数处理并通过 `requestAnimationFrame` 或短任务让出控制权，保证关闭、取消和重绘仍能执行。备用流程使用同一输入输出协议与颜色缓存，避免两套算法结果分叉。

## 导入交互

点击“快速导入”或高级向导生成按钮后：

- 立即显示处理状态和阶段进度；
- 原操作按钮替换为“取消导入”，其他会创建新导入结果的按钮暂时禁用；
- 关闭按钮始终可用，关闭等价于取消且保留导入前设计；
- 重复点击不会启动第二个并行任务；
- 完成后一次性提交图纸和一条撤销记录；
- 失败或取消不产生半成品、不改变原图、不污染历史。

快速导入明确设置并保存 `balanced`。完成消息、右侧摘要、`importRecipe.mode` 与实际算法必须一致。快速导入与高级向导共享处理结果缓存；只有影响像素结果的设置改变时才使缓存失效。

## 阿尔法锁定

阿尔法锁定是图层级属性 `alphaLocked`，与现有整层 `locked` 独立：

- 整层锁定：该图层完全不可编辑；
- 阿尔法锁定：允许修改颜色，但不允许改变空白/非空形状。

开启后，画笔、填充、描边、矩形填充、图形和换色仅能修改当前图层已有色号的格子；空白格保持空白。橡皮擦不能清除已有格子。移动、镜像、裁剪等结构工具遵循现有图层规则，不把阿尔法锁定误当成整层锁定。

图层面板提供独立的“α”开关与明确提示。该属性写入项目数据；旧项目缺少字段时默认 `false`。合并或复制图层时执行明确规则：复制保留属性，合并生成的新层默认关闭阿尔法锁定，避免意外限制。

## 相近色智能合并

颜色优化区新增“相近色合并”工作流：

- `保守`、`均衡`、`强力`三档阈值；
- 每条建议显示源色、目标色、CIEDE2000 色差、涉及豆数和预计色号数；
- 可单独应用一条建议，也可应用当前档位的全部建议；
- 用户可改选目标色；
- 默认保护轮廓色、高光色与手动锁定色；
- 目标优先级依次为：受保护色、库存充足色、使用量更多色、稳定色号顺序；
- 执行前显示变化格数和前后色号数；
- 整次应用只产生一条撤销记录。

建议计算是纯函数，不在预览阶段修改图纸。应用时重新校验源图纸指纹；若图纸已变化，则丢弃旧建议并提示重新分析。

## 按色号制作导航

现有制作模式扩展为可恢复的按色号工作流：

- 显示当前色号、颜色、总豆数、已完成和剩余数量；
- 支持上一色、下一色和“定位下一处”；
- 当前色高亮，非当前色可降低亮度，但不改变实际图纸；
- “定位下一处”寻找当前色尚未完成的连续区域，优先最近区域，并把视图平移/缩放到可见位置；
- 当前色全部完成后可按设置自动进入下一色；
- 默认顺序为使用量从多到少，用户可以改为色号顺序或手动选择；
- 单格和批量完成标记可撤销，清除制作进度保留现有确认规则。

项目保存制作完成标记、当前色号、排序方式、是否自动下一色和高亮设置。旧项目按当前图纸重新计算缺省导航状态。删除或换色后，失效的完成标记和当前色号在载入/渲染时归一化。

## 数据兼容

项目格式继续向后兼容，新增字段均为可选字段：

- 图层：`alphaLocked: boolean`；
- 制作导航：`buildNavigation.currentCode`、`sortMode`、`autoAdvance`、`dimOthers`；
- 现有 `buildCompletedCells` 继续作为完成状态的唯一来源；
- 导入配方保持现有结构，只修正快速导入的 `mode` 一致性。

不提升旧文件的强制最低版本。缺失、类型错误或引用不存在色号的字段使用安全默认值，不阻止项目打开。

## 异常与安全

- Worker 错误：终止工作线程并尝试一次备用流程；
- 内存不足或像素缓冲区失败：保留原设计，提示降低目标尺寸；
- 用户取消：停止接收进度和结果，释放大缓冲区与对象 URL；
- 背景清理过度：沿用原图回退规则；
- 任务结果过期：静默丢弃，绝不覆盖新任务；
- 相近色建议过期：要求重新分析，不执行旧映射；
- 项目保存过程中不序列化 Worker、Canvas、缓存或临时任务状态。

## 非目标

本轮不实现社区、账号、付费、颂画师体系、智能硬件连接、完整 3D 立体模型编辑或装扮养成系统。这些能力不直接解决当前导入和制作效率问题，并会引入超出本地工具定位的服务端与运营依赖。

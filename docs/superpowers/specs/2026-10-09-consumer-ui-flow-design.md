# Q像素面向拼豆爱好者的界面与制作流程设计

日期：2026-10-09。状态：两轮交互草图及 B 方向已获用户确认；本文待最终文字审阅。

## 1. 目标与决策

主要用户为拼豆爱好者，核心任务是图片转图纸、备料和跟图制作。产品表达为“把喜欢的图片，做成能真正拼出来的作品”。保留专业绘制、图纸重建、参考描绘、图层、完整品牌色板及自由调整能力。

用户已选择 B：围绕制作流程重组界面。首页与工作台以任务为中心，避免全程固定向导造成反复修改困难。两轮确认分别覆盖首页、拼制、保存反馈，以及导入、配色、导出、设备布局方向。

优先修复可信度问题，再提高第一次成功率和持续制作效率。界面改进不能承诺必然获得应用市场热门排名；通过首次完成率、任务耗时及留存相关行为评估效果。

## 2. 范围和不变约束

- 本轮包括首页、导入确认、四阶段工作台、预览和导出入口、保存与同步反馈及响应式布局。
- 全局色板不减色；“图纸用色”与“完整色板”是两个不同视图。色数优化只在用户主动选择并确认后影响当前作品。
- 保留显式保存与未保存状态。自动恢复草稿不是已保存工程；PNG/PDF 导出不是工程保存。
- 保存、导入、网络恢复均不自动上传。电脑同步始终由用户主动发起，失败时保留本机数据及待同步状态。
- 跨网络访问、CloudKit/Tailscale、账户、社区、支付、商店上架及硬件扩展不属于本轮。
- 原生 App、浏览器、安装包、真实手机/iPad、物理拼豆和智能底板验收分别记录。
- 草图的图像、色号、数量、时间均为示例，不能直接作为生产数据、色板映射或输出预设。

## 3. 首页

第一次使用且没有最近作品时，主区域呈现图片转图纸的结果示例、一个“选择图片”主按钮和“试做示例”次按钮。示例使用本地合法素材，从临时会话开始；保存前不能假装已写入作品库。

有最近作品时，主区域展示作品缩略图、名称、当前阶段、可恢复的制作进度及实际本机可用状态。主按钮继续最近任务，次按钮编辑图纸。最近任务在本机成功保存后记录；失效的记录回退到作品列表。仅有电脑索引、没有本机正文时，呈现“获取并打开”，不承诺离线继续。

创建入口统一用任务命名：“把图片做成图纸”“还原现成图纸”“照着参考图画”“自己画”。所有入口复用现有导入路由。仍可打开 .qpx、管理文件夹、搜索排序、访问回收站和主动同步。作品库迁移及备份能力如已完成，放入作品库管理入口，不在此次改版中重做格式。

作品卡片保留完整名称可访问方式，缩略图不遮挡标题与状态。区分“此设备可离线打开”和“需从电脑获取”。不要用统一的“本机源文件”说明覆盖混合索引列表。

## 4. 图片转图纸

选择图片后，在临时会话中进行本机识别和处理，呈现原图与推荐图纸。大任务有真实进度、取消入口、失败说明和重试。图片选择取消、处理取消及关闭窗口不更改原作品。

提供“更接近原图／均衡推荐／更容易拼”三个候选，映射现有高保真、均衡、易制作处理，不另建重复引擎。候选均从不可变原图独立生成，切换时更新真实图纸及统计；尚未完成处理时不能展示旧结果为新候选。用户可跳过精细调整，继续编辑。

尺寸可选常用宽度与自定义值，高度按原图比例计算。29/58/87 格是便捷建议，不限制其他尺寸。实际尺寸根据所选豆子规格计算；缺少可靠规格时仅显示格数，不推断厘米数。底板数量依据实际所选规格和图纸分割结果计算，不只依据宽度估计。

“精细调整”保留图片类型、网格校准、背景清理、曝光、对比度、饱和度、抖色及清理强度。复杂图片和校准需求可显式进入现有高级工作台，不强制经过全部步骤。

“用这个方案继续”确认临时结果并进入画图。新作品在实际保存完成前显示未保存。对已有作品导入保留当前替换/图层语义及未保存保护，不能静默覆盖。现成色号图继续走独立重建入口并复核图例，不能当照片转换取代。

## 5. 四阶段工作台

保留画图、配色、拼制、导出四阶段，阶段可自由切换，不代表必须依序完成。像素画与拼豆图纸类型保留，但作为作品视图/设置表达，避免与任务阶段形成两个同等抢眼的导航组。

顶部突出返回作品库、作品名称、可信保存状态、保存、预览、导出。另存为、工程备份、历史等从明确的作品操作入口访问；核心能力不删除。更改名称不等同另存为。

### 画图

主画布、基础绘制、当前色和图层优先。区域工具、扩容、裁剪、图形、描边、参考图和高级能力可展开访问。使用完整名称或可见解释，避免只用“矩填／区删”等不易理解缩写。破坏性操作保留撤销、检查点及现有确认规则。

### 配色

显示全部图纸用色、用量、当前色及可搜索的完整色板入口。相近色合并、色数优化、批量替换先展示影响和预览，用户确认后应用并建立检查点；取消不改变作品。

库存为可选能力。完全未设置时显示中性“库存尚未设置”，不称为缺货；已设置但部分色号未录入时明确未知项及估算口径。备料清单仍展示全部需求、库存与需补数量，允许复制及 CSV，不截断。主动选择“仅用库存重配色”才改变配色；导出清单不扣库存。

### 拼制

默认突出当前色、当前底板/区域、局部和总体进度、定位下一处、上一色/下一色以及缩放。完整图纸可查看，不因突出当前色丢失上下文。保留按色号、行或区域推进、自动下一色与底板导航。

本阶段画布点击只标记完成，不改变格子色号。隐藏绘制、橡皮及删格操作；需要改图时显式切到画图。阶段切换不清除制作进度。进度计入工程修改、保存和恢复，未保存的进度也明确提示。

### 导出

入口按目的分为“打印图纸”“材料清单”“展示作品”，每种出口只显示相关选项及预览。

- 打印图纸：PDF/既有图纸 PNG、逐板分页、色号、用量、纸张和边距；保留既有镜像等选项。
- 材料清单：全部色号、需求、库存、缺口及估算说明；CSV 与文本复制。
- 展示作品：平面或 3D、构图比例、背景、作品名称及分辨率，保留 4K 能力。

工程 .qpx 备份独立命名。文件成功写入/下载后才提示导出成功；取消不是错误，失败可重试。当前未保存修改也可输出时，不把输出成功误报为工程保存。分享须由用户主动操作，不自动发布或上传。

## 6. 成品预览

一个预览入口，保留平面/3D 切换。打开时以作品清晰、完整入画为默认，少量风格预设优先。详细材质、光照、烫法、透明度等可展开，保留已有控制范围。

默认观察；编辑是显式切换，观察拖动不落笔。仍显示“参考模拟 · 未实物标定”，不能把视觉效果当实物准确性。预览和图纸输出的入口及结果分别表达。材质预设不更改图纸色号。

## 7. 保存、离线与同步状态

三个维度独立表达，依真实持久化结果和同步记录判断：

| 维度 | 用户可见状态 | 依据 |
| --- | --- | --- |
| 当前修改 | 未保存、保存中、保存失败、已保存到此设备 | 当前修改版本与本机成功写入版本 |
| 离线使用 | 可离线打开、需从电脑获取、离线入口准备中 | 本机完整正文及入口离线资源就绪情况 |
| 电脑同步 | 未同步、待同步、同步中、同步未完成、已同步 | 明确同步成功记录与该记录对应的作品版本 |

没有待同步标志不能单独证明已同步；有本机正文也不能证明服务器持有该版本。缺少同步证据时显示未同步或尚未确认。当前修改未保存时，可以显示“上次保存版本已同步”，避免暗示新修改已上传。

状态区显示最近成功保存/同步时间。同步失败说明本机保留情况及重试入口，不承诺本轮范围外的跨网访问。不同网页 origin 的保存区独立，迁移说明保留并可按需展开，不承诺自动找回旧地址数据。

冲突副本保留，版本时间、来源和比较入口帮助用户选择；本轮不改变并发协议或静默覆盖策略。没有真实差异数据时不伪造比较结果。

设计检查以当前作品快照更新。打开作品、导入确认、编辑、阶段切换和保存后须刷新相关结果，避免“已显示图纸但尚未生成”状态。检查只对可验证的内容下结论，未录入库存不是图纸错误。

## 8. 响应式和可访问性

电脑：画布与当前任务面板并排，次级工具折叠；保留快捷键和说明。

平板：横屏可以并排；竖屏优先画布，任务设置从底部面板打开。面板关闭后能继续操作画布，不能有透明层截获触控。拼制时当前色、进度与下一处始终容易取得。

手机：单列和可折叠设置，关键操作在底部安全区域内。拼制参数放入底部面板，图纸可缩放/移动；不会把长设置面板永久挤在图纸旁。模拟窄容器只是设计预览，不能替代实际 viewport 和触控验收。

可点击目标建议至少 44 × 44 CSS px；焦点可见，按钮有可访问名称，阶段及状态不只靠颜色表示。一般文字与背景满足 4.5:1 对比度，大字满足 3:1。图纸色号不得随界面主题改变，背景与选中样式不能掩盖颜色判断。

## 9. 接入与现有工作协调

沿用 app.js 的导入会话、工程保存、渲染、用量统计及制作进度。阶段组织沿用 workspaces/workspace-controller.js、context-inspector.js、quality-checks.js 和 studio.css；不新建平行工作台数据模型。

2026-10-09 当前工作区存在未提交的 web/core/save-status.js、project-library.js、offline-projects.js、app.js、HTML/CSS、服务与打包脚本改动。实施前核对其最终状态及所属工作，保留并复用相关能力，不覆盖或将它们计入本轮成果。

界面状态与展示尽量由小型独立模块派生，保存和同步仍由现有服务执行。新增核心模块必须同步到打包与发布校验清单。功能降级、WebGL 不可用及处理失败仍能返回稳定编辑流程。

## 10. 验收与交付

先在隔离会话/测试作品中验证，不使用真实作品进行破坏性测试。核心路径包括：

1. 新用户示例/图片 → 推荐结果 → 可选精细调整 → 画图 → 保存 → 返回首页 → 再打开，名称、尺寸、图层、用色一致。
2. 导入中取消/关闭/失败重试；旧工程与未保存修改保持原有保护行为；迟到的异步结果不覆盖已取消会话。
3. 配色预览取消和应用、撤销/检查点恢复；完整色板和全部材料条目不丢失。
4. 拼制按色/行/板推进、进度保存和重新打开；画布点击不改色，阶段切换不清零。
5. 保存失败、同步失败、未下载正文、新建未同步、上次版本已同步和冲突副本的状态与事实一致。
6. 打印分页与实际比例、材料中文 CSV、平面/3D 图片、.qpx 备份；成功/取消/失败各自反馈，输出不伪报工程保存。
7. 390 × 844 手机、744 × 1133/768 × 1024 竖屏平板、1024 × 768 横屏平板和电脑宽屏，检查焦点、面板遮挡与操作回到画布。

实施后运行有意义的状态与数据回归、npm test、npm run build、git diff --check；打包候选 App 后发布校验和资源哈希核对。安装和运行服务更新按已授权发布范围执行，保护未保存会话；真实 iPad/硬件不可用则明确未验收。

设计效果单独做首次用户观察：能否无讲解完成并保存第一张满意图纸、各阶段任务耗时、误触及求助点、作品能否安心找回。记录基线和改版差异；不在本轮自动接入第三方遥测或上传作品。

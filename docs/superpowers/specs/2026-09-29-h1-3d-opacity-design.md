# 成品 3D 的 H1 透明度设计

日期：2026-09-29

## 问题与目标

当前成品 3D 依色卡光学类别分组，H1 与 H2 均落入不透明材质组；已保存的 H1 白色不透明度只影响样式和导出图纸，截图中的标准融合预览因此把二者画得几乎一样。

成品 3D 的 H1 采用与样式、导出预览相同的 0–100% 白色不透明度；H2 始终以不透明白色绘制。3D 工作台增加同一设置，调整后立即更新模型并写回工程设置。不添加辨识标记或改动色号编码。

## 绘制与数据

- H1 从普通不透明材质中独立分组，逐颗和融合表面都用可调 alpha 的白色材质；H2 维持不透明组。现有 T1 扩展透明材质保持独立，不随 H1 设置改变。
- 3D 工作台初始读取工程的 `exportH1Opacity`，其滑杆与样式、导出预览写入同一数值；保存重开后恢复。0% 时 H1 不可见，20% 时透出布景且留下淡白材质，100% 时为白色不透明。
- 3D 背板和布景按原设置绘制；浅色背景上差别可能较弱，验收同时用浅、深背景以及正面、斜侧面观察。H1 不投射不透明阴影。
- 现有 H1 白色色值保持，用途说明更新为可调透明白；不更改项目源文件的色号。预览继续标注未实物标定。

## 验证

检查 H1/H2 相邻图样在未烫、标准融合下的 0%、20%、100% 外观，深浅背景切换、滑杆即时响应、保存重开、3D PNG 导出与安装后的服务资源。实体 iPad 操作需在设备上单独验收。

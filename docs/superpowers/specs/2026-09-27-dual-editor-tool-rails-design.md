# 画布左右双工具栏

## 目标

在专业拼豆图纸编辑界面恢复左右对称的浮动工具栏，减少左上角工具堆叠，保留原有工具的功能与快捷操作。

## 布局与交互

- 左侧固定浮栏只放“绘制”：画笔、取色、近期颜色、橡皮、填充、色板。
- 右侧浮栏放“区域”和“辅助”：区域包含选区、矩填、区删、去背景、图形、描边、清空；辅助包含移动、配色、辅助线。两组标题独立显示，展开一组时收起另一组。
- 两栏均可收起；右栏可拖动并记住自定义位置。首次进入时右栏靠画布右上方，窄屏默认收起，用户手动展开后记住选择。
- 工具参数浮层显示在所选工具同侧；底部色号条与右栏留出不重叠空间。现有设置面板仍在画布外侧。

## 验证

检查工具分组与点击响应、右栏展开和拖动、左右工具参数位置、窄屏收起、缓存更新及发布包资源一致性。

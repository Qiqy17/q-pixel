# Q像素背景、封面与无孔成品材质设计

日期：2026-09-24
状态：用户已审核通过 A 路线；已进入实施
适用：本地 Web、macOS App、平板浏览器

## 1. 目标与依据

本轮按三个工作包实施：A 背景材质与封面目录，B 样式预览参数折叠，C 成品质感 3D 重建。A 与 B 先交付可用的展示图流程，再完成 C；发布时一起回归。展示图负责布景与排版，3D 负责熨烫后的形态和光学响应。两处都必须保留源图的色号及可编辑工程。

用户提供的七张《各类烫法展示数据》图片只作**视觉参考**：它们呈现常规无孔、布纹、闪片、粗细纹、压纹等可观察特征，但并非同批 MARD 5 mm、固定光照与相机的测量样片。不得从这些拼图和社交截图拟合绝对色号、毫米尺寸、温度或反射率；不得把图片打包进 App 或标成 MARD 已标定。

公开案例用于确认创作方向，不用于推断平台用户的总体偏好或复制作者照片：[抖音无孔成品案例](https://www.douyin.com/video/7611524955252156288)、[抖音多种布面与闪面烫法](https://www.douyin.com/shipin/7595782114067662891)。小红书搜索页在本轮访问时返回平台安全限制，因此该平台的直接样本尚未取得；现有七张带平台水印的图片也只按用户提供的参考观察。背景素材候选优先选用[Poly Haven CC0](https://polyhaven.com/license)并逐项记录来源、许可、下载版本和本地哈希。

## 2. 现状与边界

- `web/app.js` 已定义大量背景值，但 `renderMaterialPicker()` 目前仅展示七个精选项；单纯开放全部旧选项会把程序化换色、真实照片纹理和装饰效果混在一起。
- `web/index.html` 的样式预览把边框、阴影、画幅、光线和装饰连续堆放，常用的选背景与看成品被长参数列表挤开。项目保存的设置不应因折叠状态变化而改变。
- `web/3d/finish-viewer-entry.js` 主要以逐颗管状网格和局部连接颈表现烫法。对无孔、无明显豆间隙的成品，必须改表面拓扑；只调孔径或加纹理不足以得到连续图案。
- `web/3d/calibration-manifest.json` 仍为 `uncalibrated`。本轮改进参考级预览，保留“参考模拟 · 未实物标定”标识。

## 3. 背景材质与封面目录

### 3.1 精选目录

首批以使用场景分类，默认只显示经过视觉核查的约 12 个选项。旧项目仍能读取原背景值，并在“旧项目材质”中继续选择；未通过质量检查的旧值不进入精选目录。

| 分类 | 首批候选 | 用途与要求 |
| --- | --- | --- |
| 纸张手作 | 米白棉纸、牛皮纸、方格手账纸 | 低反射、可见细纤维或印刷网格；为标题与标签留白 |
| 织物 | 天然亚麻、厚毛毡、柔绒布 | 编织方向和尺度可信；小图案边缘有接触阴影 |
| 桌面木石 | 浅木、暖灰石膏、深灰板岩、大理石 | 有真实尺度和材质差异；避免所有底色只换色调 |
| 摄影棚 | 暖中性、深中性 | 背景克制、双侧柔光；适合检查浅色、透明或闪面成品 |

每个条目记录 `id`、中文名、分类、推荐图案类型、来源与许可证、纹理路径、缩放尺度、默认布光和预览缩略图。照片纹理与程序化纹理在元数据中分别标识；不得称后者为实拍。材质不直接改变图纸色号。离线无图时使用指定的程序化回退，并提示当前使用回退材质；自定义背景失败后保持上一张有效图。

### 3.2 封面版式

封面是独立于背景材质的构图选项，首批四种：干净居中、手作桌面、信息卡、拼贴展示。版式控制作品位置、比例、留白、标题/色号信息区和边框默认值；同一个背景可切换版式。拼贴展示在首批只使用同一工程的主图与局部放大，不自动调用外部照片。默认版式不加文字或水印；用户选择后才显示可编辑信息。导出采用与屏幕预览相同的合成顺序与坐标。

### 3.3 数据与代码边界

新增小型场景目录模块，集中保存精选项和旧值映射；`web/app.js` 保留现有项目设置、预览入口和导出接口。背景位图只作为布景的漫反射基础图；粗糙度、边缘暗角和接触阴影由场景参数处理。需要扩充 CC0 素材时保存来源、作者、许可页面、获取日期及 SHA256，不抓取小红书或抖音图片入包。素材目录不会成为运行时联网依赖。

## 4. 样式预览参数分组

打开预览时固定可见：背景材质、封面版式、画幅比例及作品预览。其余用原生 `<details>` 分成“边框”“阴影与厚度”“光线与装饰”“高级尺寸/自定义背景”。组标题显示当前关键选择，如“边框 · 无”或“阴影 · 柔和”。边框类型为“无”时隐藏大小和颜色；不用自定义比例时隐藏宽高输入。折叠只影响界面，不修改任何已保存值。

触控目标至少 44×44 CSS px。键盘可通过 Tab、Enter、Space 操作分组；关闭并重开弹窗时仅保留本地 UI 展开状态，不写入 `.qpx`。在 820×1180、1024×768 和 1440×900 下，预览主体与设置区各自可滚动，关闭按钮始终可达，不能发生横向溢出。删除重复或无明显效果的选项前先核对旧工程兼容性；旧值至少能回退读取和导出。

## 5. 无孔成品 3D

### 5.1 形态模型

建立按正反面描述的 `surfaceTopology`，使形态与烫法表面分开：

- 未烫与明确标为有孔的状态保留逐颗豆体、孔洞及高度。
- 常规无孔、平融、毛巾、澡巾、格纹、细闪、粗闪等成品正面使用**连续无孔表面**。从图纸占用格生成合并的顶面与阶梯轮廓侧壁，顶面共享边界，不能留下每颗豆之间的黑缝或显眼的连接桥。
- 背熔等不对称状态分别定义正面和背面的拓扑、孔洞及厚度。切换视角显示对应真实几何，不用一张贴图假装背面。
- 旧工程中既有十个 profile ID 继续可读；新增视觉变体另设稳定 ID 与中文说明，不改变用户已有设置的含义而不提示。

可见颜色通过最近邻色块贴图或等价的无缝顶面属性保持图纸分区；外轮廓按占用格提取。无孔顶面需要连续法线，色块边界仍清楚。透明扩展色与不透明白色使用不同光学路径；大图或弱设备对透明传输降采样时显示画质档位。500×500 按块生成并限制同时驻留的几何、纹理和阴影，操作与取消不能被一次长同步循环锁住。

### 5.2 表面材质与光线

表面纹理使用与豆径对应的物理尺度：毛巾为细软、随机纤维压痕；澡巾为较粗方向性网纹；华夫格为有规律正交压纹；细闪与粗闪控制亮片尺寸、密度和角度高光；镭射/幻彩有角度变化但不能把底色洗白。纹理作用于连续成品表面，不能铺在背景上或统一覆盖整幅图案的颜色。

默认提供固定的中性对照光、浅/深背景、正面/背面/斜侧面视角。同一图案比较烫法时相机与光照保持一致；另提供可调环境光强度与冷暖，界面明确区分“观察光照”和“图纸色号”。色卡 HEX 不是实测颜色，不给出精确色差数值。曝光和色调映射不得使白、透明、浅黄色及深色豆无法区分。屏幕与 4K 导出使用同一场景和材质定义。

### 5.3 参考图记录与校准状态

为七张图片建立仅用于分析的记录：文件名、画面中标注的烫法、可观察形态、纹理方向/粒度、反光类别、背景/灯光不确定性与可信等级。记录引用本地用户文件路径，不将原图复制到发布包。相同图案、相同拍摄条件的照片可帮助相对比较；跨图、跨创作者的照片只用于判断方向。MARD 实物标定仍需受控样片、正侧背与量尺照片、光源及工艺记录，并经单独验收才可改变清单状态。

| 用户文件 | 可观察到的主要线索 | 使用边界 |
| --- | --- | --- |
| `各类烫法展示数据1.png` | 同一粉色图案的常规、布面、压纹、粗闪和细闪外观；上半部含原图色号 | 拼贴排版与拍摄条件不明，只比较形态和纹理类别 |
| `各类烫法展示数据2.jpg` | 同一蓝色图案中，常规无孔、澡巾、毛巾、双面有孔、闪面、亮面和布纹的相对差异 | 可作相对表面特征参考，不按图中文字推断工艺参数 |

## 6. 错误处理与兼容

- 背景资源丢失或解码失败：回退到程序化中性背景，保留用户原选项标识和源工程；导出与预览一致。
- 3D WebGL 不可用、上下文丢失或内存不足：给出可读提示，画图与普通展示导出继续可用；用户能关闭或重试。
- 设置迁移：未知背景和烫法值安全映射到接近的旧选项，原始值随项目保留以便以后恢复；新设置不会重写旧工程，直到用户明确保存。
- 参考素材授权不明时只保留来源与分析笔记，不进入资源目录或安装包。

## 7. 实施顺序与验收

1. 整理材质元数据与来源记录，精选目录及四种封面版式；核对预览和导出一致，保持旧值可读。
2. 将密集参数改为可折叠分组并处理无关控件显隐；完成键盘、触控与平板布局回归。
3. 将 3D 分为有孔豆体与连续无孔表面两条形态路径，再接入按尺度生成的布纹、压纹和闪面；加入固定对照光和环境光控制。
4. 使用相同图纸生成各烫法、正反侧、浅深底对照图；验证原色和透明/白色区别。测试 30×30、120×120、500×500 的启动、交互、取消和 4K 导出，记录设备、浏览器、耗时和降档行为。
5. `npm test`、构建、默认 `/test.html`、专业工作区路径、安装版 App、服务健康与资源哈希全部通过后更新构建号并发布。目标 iPad 与受控 MARD 样片缺席时明确记为待确认；不得称本轮为实物标定。

成功标准：用户能快速从少量高质量背景与封面中找到合适布景；高级参数不妨碍预览；绝大多数成品烫法呈连续无孔图案，区别主要由真实可见的表面纹理、反光和厚度表达；原色、透明豆、旧工程和离线使用均不回退。

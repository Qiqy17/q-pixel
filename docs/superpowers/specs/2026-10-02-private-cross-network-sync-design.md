# Q像素跨网络同步替代方案：私人网络直连

日期：2026-10-02（北京时间）。状态：方案候选，待用户选择及审阅；尚未安装软件或实现接入。

## 目标与前提

延续已完成的离线保存：平板先本机保存，在另一可用网络中点击“同步电脑文件”，将作品同步到电脑。用户目前尚无 Apple 开发者账户，现阶段没有可用的 Q像素 CloudKit 配置。

这份方案覆盖“电脑开机联网时跨网络同步”。电脑关机时的云端上传与稍后接收，需要另一个云端中转方案，不在私人直连的验收承诺内。

## 两种路线

| 路线 | 用户操作与依赖 | 成本与边界 |
| --- | --- | --- |
| 推荐先做 Tailscale 私人直连 | 电脑和平板安装 Tailscale，加入同一个私人网络；首次账户登录和系统 VPN 配置由用户完成 | 复用当前电脑作品服务，无需 Apple 开发者配置；同步时电脑必须开机联网，平板需连接 Tailscale |
| 云端中转 | 固定 HTTPS 入口、云端存储、账户认证、部署归属及运行费用确认 | 电脑关机时平板仍能上传，电脑之后接收；实现和维护范围更大，不能复用局域网接口直接冒充云同步 |

本机检查没有发现 Tailscale CLI 或 /Applications/Tailscale.app。私人直连必须先得到用户对客户端与账户依赖的明确选择。

## 推荐路线的具体设计

1. **稳定入口**：Tailscale Serve 将本机服务代理为设备专属的 HTTPS 地址，限私人网络可达。固定设备名与 tailnet 域名后，两端始终使用同一入口；更换 Wi-Fi 不切换为新的局域网 IP 地址。
2. **数据流**：平板 IndexedDB → 用户点击同步 → 固定 HTTPS 入口 → 电脑 Q像素服务。正文和待同步修订保留现有事务与回读确认流程；网络恢复不自动上传。
3. **身份与网关**：新增仅监听 127.0.0.1 的远程接入网关。对外核对配置的 HTTPS Host/Origin 和 Tailscale 提供的用户身份，仅放行用户指定账户；对内转发到既有 8766 服务。其账户和设备限制需与 tailnet 访问规则共同验证。
4. **现有保护兼容**：当前 Python 服务严格校验 Host/Origin，不能直接假设反向代理即可使用。网关应明确验证外部来源后发起规范的内部请求，保留原局域网服务的来源与配对检查。
5. **功能范围**：转发应用静态资源、项目及缩略图、同步健康和现有作品设置接口；远程接入不开放文件下载目录、AI 密钥配置和其他管理接口。配置不完整时网关拒绝启动。
6. **界面状态**：服务提供连接方式信息，首页显示“局域网同步”或“跨网络私人连接”；电脑睡眠、Tailscale 断开或身份过期时提示无法连接，保留待同步记录，不报同步成功。
7. **新入口迁移**：浏览器存储按 origin 隔离，不能读取旧局域网入口的 IndexedDB。电脑已保存作品可在新入口手动同步后按需打开；平板仅本机存在的作品先在旧入口导出 .qpx，再在新入口导入。保留旧入口数据，切换前不刷新有未保存内容的页面。
8. **启停**：检查现有 Tailscale Serve 配置，避免覆盖其他服务；建立独立网关启动配置，提供关闭 Q像素私人连接的操作。远程入口开启与软件安装属于后续用户确认后的实施步骤。

## 验证与交付

- 先用隔离网关和测试作品验证身份不匹配、非法 Host/Origin、接口范围、保存回读、断连队列保留；不拿用户原稿做破坏测试。
- 电脑在家庭网络、平板用另一 Wi-Fi 或手机热点：旧入口备份迁入 → 离线编辑保存 → 重开 → 连接 Tailscale → 点击同步 → 电脑回读一致。
- 检查双端同时修改的冲突副本、同步期间新保存、重试不重复副本。
- 电脑休眠/关机时应保留本机待同步；恢复电脑后再次点击同步成功。不能将私人直连标为支持关机云上传。
- 桌面模拟、网关测试、真实 Tailscale 连接和真实 iPad 验收分别记录。当前真实 iPad unavailable，没有实物跨网验收证据。

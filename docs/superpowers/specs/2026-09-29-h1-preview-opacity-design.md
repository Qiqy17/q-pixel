# H1 预览透明度统一设计

日期：2026-09-29

## 目标

样式预览与导出预览共用 H1 的白色不透明度设置。H1 可在 0–100% 间调节，例如 20% 时按 20% 白色叠加在选定背景上；H2 始终以色卡白色不透明绘制。用户选择不添加辨识角标或其他装饰。

## 实现

- 沿用工程已有的 `exportH1Opacity` 数值及导出预览滑杆，在样式预览增加同一数值的滑杆。两处调整立即同步数值和预览，保存工程后恢复该值。
- 在“导出”阶段提供样式预览入口，确保可从当前编辑界面使用该滑杆。
- 样式绘制 H1 时采用该数值作为 alpha，H2 与其他色号保持不透明。导出绘制沿用现有 H1 alpha 逻辑，更新两处文案以明确 0% 为完全透明、100% 为不透明。
- 实际导出的图纸及样式图按相同绘制规则生成，不加入仅预览可见的标记。白色背景下，半透明白与不透明白可能视觉接近，这是叠色结果；在深色背景下验收区分度。
- 保留现有色号编码，不迁移旧工程的 H1/H2/T1 数据。3D 材质语义不在此次两种 2D 预览修正范围内。

## 验证

检查 H1 在 0%、20%、100% 时两处预览及导出像素随透明度变化；H2 像素始终不变。检查两个滑杆联动、工程保存重开、原有导出选项与桌面安装包。

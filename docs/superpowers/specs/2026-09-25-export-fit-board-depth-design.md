# 导出适应、3D 背板与融合侧面设计

用户已确认以下行为。

## 导出预览

打开弹窗后，以实际可见画布区计算缩放，完整显示图纸，并保留少量边距。每次打开重新适应；打开后的加减按钮只改变本次视觉缩放。适应不设会裁切大图的固定下限，缩放只修改 CSS 显示尺寸，不修改导出像素或图纸内容。视口变化时，仅在仍处于自动适应状态时重新计算。

## 3D 背板

画面分为共用的外层布景和独立的图纸背板。背板默认透明，可选择透明、纯色或图片，并独立调节透明度。图片从本地选择，校验类型和大小，随工程设置保存；加载失败时显示错误并保留原状态。背面观察隐藏背板。编辑拾取仍使用虚拟平面，不依赖背板可见性。快照与 4K 导出合成相同的背板及外层布景。

## 融合侧面

融合预设保留连续的正面色面与纹理；只在外缘生成圆润过渡和有厚度的侧壁，使斜侧视角有明确体积。内部邻接边不生成侧壁，以免出现裂缝。完全平融保持相对平整。仍按条带构建几何，避免为每一颗融合拼豆创建独立网格；不同画质档位控制边缘细分。此模型仍标注为未实物标定参考效果。

## 验证

用大尺寸图纸检查打开即完整适应、加减与再次适应；用空白和非空工程检查背板各模式、保存重开、快照与 PNG；检查毛巾烫斜侧与正面、性能和图纸编辑；最后运行项目测试、构建及 App 发布包校验。

# 单图层按格移动设计

日期：2026-09-29

## 目标

在普通拼豆工程中，用户可以对任一导入或新建图层输入正整数格数，分别向上、下、左、右移动。只改变该图层的格子内容，不改变其他图层、画布尺寸或图层属性。

## 交互

- 每个图层的“更多”菜单增加“移动图层”：格数输入框及四个方向按钮。操作直接作用于该行图层。
- 仅接受 1 至 500 的整数；锁定图层及分区工程禁用此操作。隐藏但未锁定的普通图层仍可移动。
- 超出画布的非空格裁掉。裁掉前显示具体格数并征求本次操作确认；取消不改变工程。
- 空图层移动不产生历史记录。成功移动后提示方向、格数及裁掉数量。

## 数据与可靠性

- 纯函数按位移生成等尺寸新格子矩阵并统计裁掉的非空格，不修改原矩阵。
- 用户确认后，为一次移动写入一次撤销快照，再替换目标图层矩阵；随后重新合成可见图层、刷新画布和用量、标记未保存。撤销与重做恢复完整图层状态。
- 保存沿用现有工程图层序列化；移动不新增文件字段。透明锁、可见性和名称保持原值。

## 验证

验证四方向移动、边界裁切、取消、空图层、锁定与分区限制、独立图层、撤销重做、保存后重开，以及桌面 App 发布包内容和签名。

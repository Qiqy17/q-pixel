# 平板配对记住 30 天

## 目标

在电脑手动开启平板共享的前提下，同一平板浏览器首次输入当次配对码后，30 天内再次连接无需输入。电脑能够立即撤销所有已记住的平板。

## 方案

- 每次启动共享仍生成临时配对码，仅供新平板使用；共享服务关闭后局域网入口立即失效。
- 成功配对时生成独立随机凭证，平板以 `Secure`、`HttpOnly`、`SameSite=Strict` Cookie 保存 30 天。电脑只存凭证的 SHA-256 摘要和固定到期时间，文件权限为 `0600`。
- 每次请求先检查凭证摘要及到期时间；不自动延长有效期。未配对的 API 返回 401，页面跳转至配对页。
- 电脑运行 `run_ipad_server.sh --forget-devices` 删除已记住凭证。运行中的共享服务也会在下一次请求时发现撤销。
- 更换浏览器、清除网站数据、局域网 IP 变化或 30 天到期时重新配对。

## 验证

验证首次配对、重启共享后免配对、错误来源拒绝、到期拒绝、撤销立即生效，以及安装包内脚本与源码一致。

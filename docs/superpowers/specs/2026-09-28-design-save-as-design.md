# 设计文件另存为

## 目标

在编辑器顶部提供“另存为”，从当前图层生成新的可编辑设计文件，原设计、图层和保存状态不变。

## 交互

- “合并为一个设计”：按图层自底向上的顺序合成所有图层，包括隐藏图层；透明格露出下层内容。输入新名称后生成一个单图层设计。
- “图层逐个另存”：可单选、多选、全选图层，并分别修改新设计名称。每个选中的图层生成一个单图层设计，锁定和隐藏状态不阻止另存；新设计中的图层可见且可编辑。
- 普通图层沿用原画布尺寸；分区图层裁切到该分区的画布尺寸。若分区小于编辑器允许的 16 格边长，在右侧和底部补透明格以便重新打开。合并分区工程时生成原工程完整画布的普通单图层设计。
- 完成后，新设计出现在作品列表；结果中提供每个 `.qpx` 的下载入口。取消或失败不改动原设计。

## 数据与验证

派生文件使用新的 ID、创建时间和名称，清除原设计的分区布局、导出区域、检查点及拼制进度。先生成所有文件，再写入本机作品列表并尝试同步。验证图层顺序、隐藏图层、分区裁切、多选命名、保存重开及 `.qpx` 导入。

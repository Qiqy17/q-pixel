# Q像素后台管理第一版方案（已确认实施）

目的：无需查终端即可了解当前交付版本、服务、作品备份与同步问题。

推荐本机管理台，与已有电脑服务集成，路径 /admin，只允许电脑回环连接；平板代理即使已经配对也不提供管理接口。第一版默认只读，避免操作用户作品。卡片显示安装版本／界面修订、电脑与平板服务状态；作品列表复用轻量索引（含已删除状态）；备份列表显示日期、大小，提供用户明确点击的导出；同步诊断显示客户端待同步／冲突／失败，服务端不冒充读取各浏览器私有队列。日志只显示结构化错误摘要，不显示 API 密钥、配对码或作品正文。新增入口放在电脑首页。

方案比较：仅提供文档与终端命令成本最低但使用不便；本机管理台复用现有服务，成本中等，是推荐方案；云端用户／会员／订单后台需要认证、权限、数据库、支付及运维，成本高，另立项目。

第一版不提供删除、恢复覆盖、远程管理、账户收费。后续写操作需要权限和二次确认，恢复先生成副本。后台不替代每个浏览器本机保存区，也不启用待定跨网络方案。

验收：回环请求可访问；非回环、平板代理、错误 Host/Origin 均拒绝；没有密钥或配对码输出；作品和备份数据不被只读访问改写；原同步安全用例仍通过。

用户已确认本机管理台第一版。原生 App 通过固定地址桥接在默认浏览器打开，保留原生创作窗口；仅能读取打开管理台的浏览器同地址保存区。运营后台另行设计。

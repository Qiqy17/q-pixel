# 统一预览工作台设计（已确认）

用户确认一个「预览」入口，工作台内切换「成品 3D」和「平面展示图」。现有平面展示图的构图、文字、贴纸、边框和导出继续使用原控件与绘制链；3D 保留默认观察、明确切换编辑。

- 烫法预设改为可折叠分组，编辑图纸时默认收起，不再固定占用左侧列。
- 编辑图纸复用 Q像素主画布的真实工具栏、工具参数、色板、图层与撤销记录；工作台关闭后控件回到原位置。
- 3D 背景使用平面展示图的材质、颜色、透明度设置。3D 画布保持透明，将共享背景绘在其后，导出时合成。平面展示图已有背景选项仍是唯一设置源。
- 不支持 WebGL 的设备仍可进入同一工作台的平面展示图，并获得明确提示。

验收：桌面和平板可打开统一入口、切换双视图；烫法预设可折叠且编辑时自动收起；实际工具/图层操作在 3D 编辑后与主画布同步；背景材质/颜色/透明度跨视图一致；透明背景可导出；关闭后主画布控件正常；源站、测试、安装包分别复核。

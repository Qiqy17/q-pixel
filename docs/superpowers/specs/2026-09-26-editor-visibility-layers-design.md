# 图纸编辑可见性与图层界面

## 目标

让主画布和预览工作台的编辑状态容易辨认，常用显示项与辅助线容易控制，图层面板节省空间且文字明确。保留现有图纸、撤销、图层和去背景数据流程。

## 界面

- 预览工作台进入“编辑图纸”后，在画布上方显示画布宽高、当前工具，以及色号、网格、辅助线开关。色号和网格继续使用现有预览设置；辅助线开关仅控制显示，保留线的位置、导出分区依据及单条/全部删除功能。缩放过小时提示色号和网格可能隐藏。
- 主画布及 3D 编辑画布根据当前工具展示对应的形状光标；观察视角继续使用抓手光标。光标随工具切换立即更新。
- 主编辑器图层面板可折叠。每层采用紧凑行，明确显示名称、画布尺寸、选中状态和“显示、锁定、透明锁定”操作。复制与镜像放入该层操作菜单，合并、分组、导入继续保留在面板顶端。预览工作台复用同一图层列表。
- “去背景”入口移到左侧“区域”工具组，不保留顶部“更多”中的重复入口；原去背景弹窗、预览、撤销与图层限制不变。

## 数据与验证

辅助线显示状态随项目编辑设置保存；预览设置继续走现有 `finish3d` 保存路径。图层的展开状态为本机界面偏好，不影响项目内容。验证主画布和 3D 编辑的显示切换、光标、图层操作、去背景入口、保存重开，以及桌面包资源和浏览器回归。

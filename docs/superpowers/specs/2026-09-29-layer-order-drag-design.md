# 图层拖动排序设计

日期：2026-09-29

## 目标

普通工程的图层可以通过独立手柄拖动改变叠放顺序。列表从上到下表示从前到后；改变顺序后，重叠格子的画布显示、预览和导出随之更新。

## 交互

- 每个图层行增加拖动排序手柄。鼠标或触屏按住手柄即可上下拖动；名称输入和其他按钮保留原有操作。
- 拖动时高亮源图层，并在目标行上方或下方显示插入线。松手时提交一次排序；放回原位、按 Esc 或手势取消时不改变数据。
- 列表靠近边缘时自动滚动，使多图层工程可以跨屏排序。手柄支持键盘方向键逐层移动。
- 锁定和隐藏的普通图层可以排序；锁定只限制内容修改。分区工程的图层位置固定，排序手柄禁用。

## 数据与历史

- 使用现有 `state.beads.layers` 数组表达顺序，数组后方覆盖前方；界面按反序显示。排序只移动同一个图层对象，不修改格子、名称、可见性、锁定或画布外内容。
- 只有实际顺序变化时记录一次撤销快照，再重新合成图纸、刷新画布与列表、标记未保存。现有工程存储格式与撤销/重做继续保存数组顺序。
- 3D 预览工作台复用主图层面板，因此排序手柄和更新后的顺序在两处一致。

## 验证

检查鼠标和触屏拖动、跨多行排序、顶端与底端落点、取消、键盘、锁定与隐藏图层、分区工程限制、重叠色块显示、撤销重做，以及保存重开后的顺序。发布时校验安装包与平板服务。

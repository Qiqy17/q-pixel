# 编辑布局、光标与离线材质库设计

日期：2026-09-26。用户已批准按此方案实施。

## 范围与交互

- 绘制类工具（画笔、橡皮、填充、取色）在编辑画布上使用透明背景的小轮廓光标，热点对准实际操作点，当前像素不被实心底遮住。平移、选择、辅助工具沿用明确的标准光标。
- 工具栏和颜色条各占固定界面区域。窄宽度可收缩或滚动，但不叠压画布操作控件。顶部导航在中宽屏压成紧凑布局，不出现重复尺寸信息或过高的三行控制区。
- 拼制导航操作按可用宽度布局，按钮文字完整可读。扫描主编辑、预览、导出及侧栏常用面板的溢出和遮挡，修复发现的同类问题。
- 材质库包含至少 64 张互不相同的真实照片纹理，按类别选择。纹理随 App 离线提供，缩略图和实际绘制使用同一资源；只在选中时解码完整纹理，加载失败时显示可辨认的回退状态。现有项目材质 ID 保持兼容。

## 实现边界

材质登记以独立清单为准，记录显示名、分类、文件、原始素材页面、许可及 SHA256。文件采用适合预览的压缩尺寸，避免全部解码占用内存。沿用现有 `scene-catalog`、背景绘制和服务工作者路径，不增加运行时外部服务依赖。素材来自 Poly Haven CC0 纹理；来源和许可随包记录。

## 验证

检查 64 张以上独立文件及哈希、离线请求、材质切换与项目重开；在桌面、中宽屏和平板宽度检查工具栏、顶部栏、拼制导航和主要弹窗的实际文字边界；运行现有测试、构建和发布包校验，并核对安装版资源。
